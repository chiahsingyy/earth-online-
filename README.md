## ✨ 主要功能

- **随机冒险**：从 200 个任务中探索日常生活，支持按类别、天气、季节和场景筛选。
- **任务稀有度**：普通、稀有、史诗、传说，随着等级提升逐步解锁。
- **成长与收集**：完成任务获取经验，发现任务、收藏图鉴、重玩喜欢的冒险。
- **冒险日志**：记录文字与照片，每篇最多添加 9 张照片，保存后可修改。
- **自由计时**：支持暂停计时，也可完成任务时手动填写耗时。
- **双主题**：天空漫游、森林手账。
- **存档备份**：导出、导入 ZIP 存档，在设备之间手动迁移进度与照片。

## 📱 Android 使用方法

1. 下载 `EarthOnline-1.0.0.apk`，在 Android 手机上打开。
2. 如果系统提示，请为用于打开安装包的浏览器或文件管理器允许“安装未知应用”，然后继续安装。
3. 打开地球 Online，抽取并领取任务。
4. 完成冒险后，填写日志并保存，获得成长奖励。

更新或卸载应用前，建议先在设置页导出存档。

## 💻 网页版使用方法

当前提供网页版下载包，尚未提供在线访问链接。

1. 下载 `EarthOnline-web.zip`，将其完整解压到一个文件夹。
2. 电脑需安装 Node.js。
3. 双击解压后的 `启动网页版.cmd`。
4. 在浏览器中打开：<http://127.0.0.1:4173>。
5. 使用期间保持启动的命令行窗口打开。

如果双击启动失败，可以在解压后的文件夹中打开终端，运行：

```sh
node serve.mjs
```

请通过上述本地服务访问，不要直接双击 `dist/index.html`。网页版需要通过 HTTP/HTTPS 运行，才能正常使用本地存储与离线缓存。

## 💾 数据与备份

- 无需注册账号，日志与进度保存在本地，不会自动在设备之间同步。
- 网页版使用浏览器本地数据库；不同浏览器、域名或端口的存档彼此独立。
- 清除浏览器站点数据、使用隐私模式或卸载应用，可能导致存档丢失。
- 在设置页导出 ZIP 可备份任务进度、日志与照片；换设备时再导入。
- 导入前建议先备份当前存档。
- 应用不上传日志、不获取位置，天气由用户自行选择。
